# ME-Control (OC-Terminal)

Панель управления МЭ-сетью (Applied Energistics 2) для OpenComputers.

## 🚀 Возможности
* Просмотр МЭ-сети и инвентаря игрока (через PIM).
* Выдача и сдача предметов (включая NBT-предметы).
* Поиск по названию (с поддержкой кириллицы).
* Сортировка списка по клику на заголовок: А-Я / по убыванию / по возрастанию.
* Горячие клавиши: F1–F6 — вкладки, `/` — быстрый поиск.
* Система прав: User / Admin / TechAdmin.
* Баны с указанием причины и срока.
* Логи операций (кто, когда и что сдал/забрал).
* Мониторинг запасов с оповещениями (редстоун + звук).
* Статистика МЭ-сети: предметы, типы, энергия, занятость дисков (байты и типы).
* График энергии («кардиограмма») за последние 40 секунд.
* Показатели крафт-процессоров (занято / всего) и время работы компьютера.
* Цветовые маркеры категорий предметов в списках (слиток / руда / пыль / еда).
* Крафт: список доступных рецептов и отправка запроса на изготовление.
* Красивый GUI с прогресс-барами и «зеброй».

## 💾 Ёмкость хранилища

На вкладке «Статистика» показывается занятость дисков. В большинстве сборок OC 1.7.10
у `me_interface` нет метода `getCells()`, поэтому общий объём сети неизвестен —
панель показывает только занятый объём с пометкой «оценка занятого».

Чтобы видеть точный прогресс-бар с процентами, укажите ёмкость вручную в `config.lua`:

```lua
config.storage = {
    -- Общая ёмкость МЭ-сети в байтах (например, 4 ячейки по 4k = 16384).
    totalBytes = 16384
}
```

Оставьте `nil` — будет использоваться автоматическая оценка.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `F1` | МЭ-сеть |
| `F2` | Инвентарь |
| `F3` | Статистика |
| `F4` | Монитор |
| `F5` | Логи (только админ) |
| `F6` | Админка (только админ) |
| `/` | Быстрый поиск (на вкладках МЭ-сеть, Инвентарь, Логи) |
| `Enter` / `Esc` | Применить / сбросить поиск |

Коды клавиш взяты из `lib/core/full_keyboard.lua` OpenOS: `F1=59 … F6=64`, `/ = 53`.
Если Minecraft перехватывает какую-то из F-клавиш (например `F3` — экран отладки,
`F5` — смена вида), вкладку всегда можно выбрать мышью.

## 🔨 Крафт

Вкладка «Крафт» показывает все известные МЭ-сети рецепты (`me.getCraftables()`).
Тапните по предмету — откроется окно «Запрос на крафт» с кнопками `-10 / -1 / +1 / +10`
и зелёной кнопкой «СКРАФТИТЬ». Строка «В сети:» показывает, сколько этого предмета
уже лежит в сети.

Запрос уходит в МЭ через `craftable.request(amount)`; если свободного сопроцессора нет,
в статус-баре появится текст ошибки от МЭ.

После отправки панель следит за статусом крафта (`isDone` / `isCanceled` / `hasFailed`,
если метод есть) раз в 2 секунды и пишет в статус-бар:

* `Крафт завершен!` — предметы готовы;
* `Крафт отменен` — запрос отменён в МЭ;
* `Крафт провален (возможно, не хватает ресурсов или CPU занят)` — ошибка.

Если `me_interface` не поддерживает `getCraftables()`, список будет пустым —
вкладка при этом не ломает панель.

### Диагностика крафтов

Если вкладка «Крафт» пустая, запустите отдельный скрипт:

```bash
test_craft.lua
```

Он покажет: есть ли `me_interface`, что лежит в `me.getCraftables`
(`type` и `getmetatable`, включая `__call`), текст ошибки вызова, длину списка
и структуру первых трёх рецептов (`name`, `label`, `damage`, `size`).

Метод вызывается напрямую (`me.getCraftables()`), без проверки `type(...) == "function"`:
в OpenComputers прокси-метод может быть таблицей с метаметодом `__call`,
и такой объект тоже вызывается. Если объект не вызывается вовсе, панель сообщит
`getCraftables: table без __call`.

Причина последней неудачи также сохраняется в `_G.last_craft_error`
и выводится в статус-бар панели: `Крафты не найдены. Ошибка: …`.

## 🔄 Обновление

Файл `version.txt` хранит текущую версию. `getcode.lua` читает его до скачивания
и после — и печатает результат:

```
=== ГОТОВО ===
Успешно: 8 | Ошибок: 0
Общий размер: 342.1 KB
Время выполнения: 12.44 сек.
ОБНОВЛЕНИЕ: v1.4.1 -> v1.4.2
Все файлы обновлены до последней версии!
Запускайте: main.lua
```

Возможные варианты последней строки:
* `Текущая версия актуальна: v1.4.2` — версии совпали;
* `Установлена версия: v1.4.2` — первая установка (файла не было);
* `ОБНОВЛЕНИЕ: v1.4.1 -> v1.4.2` — версия изменилась.

## 📊 Статистика и маркеры

На вкладке «Статистика» панель показывает:

* количество предметов и типов;
* энергию с прогресс-баром и **графиком за последние 20 замеров** (≈40 секунд),
  по одному столбцу на замер; высота столбца — уровень заряда
  (`▁▂▃▄▅▆▇█`, 3 строки);
* занятость дисков в байтах и типах;
* **Крафт-процессоры: занято / всего**;
* сопроцессоры и **время работы компьютера** (`ЧЧ:ММ:СС`).

В списках МЭ-сети, инвентаря и крафтов перед названием появляется цветной маркер:

| Маркер | Категория | Слова в названии |
|---|---|---|
| 🟨 `■` | слитки | `ingot`, `слиток` |
| ⬜ `■` | руды | `ore`, `руда` |
| 🟥 `■` | пыль | `dust`, `пыль` |
| 🟩 `■` | еда | `food`, `apple`, `bread`, `яблоко`, `хлеб`, `мясо`, `рыба` |
