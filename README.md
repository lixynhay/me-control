# ME-Control (OC-Terminal)

Панель управления МЭ-сетью (Applied Energistics 2) для OpenComputers.

## 🚀 Возможности
* Просмотр МЭ-сети и инвентаря игрока (через PIM).
* Выдача и сдача предметов (включая NBT-предметы).
* Поиск по названию (с поддержкой кириллицы).
* Сортировка списка по клику на заголовок: А-Я / по убыванию / по возрастанию.
* Горячие клавиши: F1–F6 — вкладки, `/` — быстрый поиск.
* Система прав: User / Admin / TechAdmin.
* Баны с указанием причины и срока.
* Логи операций (кто, когда и что сдал/забрал).
* Мониторинг запасов с оповещениями (редстоун + звук).
* Статистика МЭ-сети: предметы, типы, энергия, занятость дисков (байты и типы).
* Крафт: список доступных рецептов и отправка запроса на изготовление.
* Красивый GUI с прогресс-барами и «зеброй».

## 🛠️ Установка
1. Установите интернет-карту в компьютер (для загрузки файлов).
2. Загрузите файлы проекта в `/home`:
   ```bash
   wget https://raw.githubusercontent.com/lixynhay/me-control/main/main.lua
   wget https://raw.githubusercontent.com/lixynhay/me-control/main/ui.lua
   wget https://raw.githubusercontent.com/lixynhay/me-control/main/me_api.lua
   wget https://raw.githubusercontent.com/lixynhay/me-control/main/db.lua
   wget https://raw.githubusercontent.com/lixynhay/me-control/main/config.lua
   wget https://raw.githubusercontent.com/lixynhay/me-control/main/test_craft.lua
   ```
3. Запустите:
   ```bash
   main.lua
   ```

## 💾 Ёмкость хранилища

На вкладке «Статистика» показывается занятость дисков. В большинстве сборок OC 1.7.10
у `me_interface` нет метода `getCells()`, поэтому общий объём сети неизвестен —
панель показывает только занятый объём с пометкой «оценка занятого».

Чтобы видеть точный прогресс-бар с процентами, укажите ёмкость вручную в `config.lua`:

```lua
config.storage = {
    -- Общая ёмкость МЭ-сети в байтах (например, 4 ячейки по 4k = 16384).
    totalBytes = 16384
}
```

Оставьте `nil` — будет использоваться автоматическая оценка.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `F1` | МЭ-сеть |
| `F2` | Инвентарь |
| `F3` | Статистика |
| `F4` | Монитор |
| `F5` | Логи (только админ) |
| `F6` | Админка (только админ) |
| `/` | Быстрый поиск (на вкладках МЭ-сеть, Инвентарь, Логи) |
| `Enter` / `Esc` | Применить / сбросить поиск |

Коды клавиш взяты из `lib/core/full_keyboard.lua` OpenOS: `F1=59 … F6=64`, `/ = 53`.
Если Minecraft перехватывает какую-то из F-клавиш (например `F3` — экран отладки,
`F5` — смена вида), вкладку всегда можно выбрать мышью.

## 🔨 Крафт

Вкладка «Крафт» показывает все известные МЭ-сети рецепты (`me.getCraftables()`).
Тапните по предмету — откроется окно «Запрос на крафт» с кнопками `-10 / -1 / +1 / +10`
и зелёной кнопкой «СКРАФТИТЬ». Строка «В сети:» показывает, сколько этого предмета
уже лежит в сети.

Запрос уходит в МЭ через `craftable.request(amount)`; если свободного сопроцессора нет,
в статус-баре появится текст ошибки от МЭ.

Если `me_interface` не поддерживает `getCraftables()`, список будет пустым —
вкладка при этом не ломает панель.

### Диагностика крафтов

Если вкладка «Крафт» пустая, запустите отдельный скрипт:

```bash
test_craft.lua
```

Он покажет: есть ли `me_interface`, есть ли метод `getCraftables`, текст ошибки
(если вызов падает), длину списка и структуру первых трёх рецептов
(`name`, `label`, `damage`, `size`).

Причина последней неудачи также сохраняется в `_G.last_craft_error`
и выводится в статус-бар панели: `Крафты не найдены. Ошибка: …`.
